# ألعاب حكيم

موقع يجمع كل الألعاب في صفحة واحدة: https://momabdu7777-maker.github.io/

كل لعبة لها صفحتها وملف الـ APK الخاص بها في مستودعها، وهذه الصفحة تشير إليها مباشرة.
لذلك تحديث أي لعبة في مستودعها يصل إلى هنا تلقائياً، ولا تحتاج هذه الصفحة إلى تعديل
إلا عند تغيير رقم الإصدار أو الحجم المكتوب تحت اللعبة.

## إضافة لعبة جديدة

1. ضع أيقونتها (256×256 بصيغة webp) في `icons/`.
2. في `index.html` انسخ أحد عناصر `<article class="game ...">` وعدّل النص والروابط.
3. أضف لوناً للبطاقة بجانب `.sea` و`.domino` في الـ CSS (`--a` اللون الأساسي، `--b` لون العناوين الصغيرة، `--c` خلفية البطاقة).
4. حدّث العدد في شارة «4 ألعاب».
5. `git commit -am "إضافة لعبة ..." && git push`
