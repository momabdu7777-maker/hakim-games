# ألعاب حكيم

موقع يجمع كل الألعاب في صفحة واحدة: https://hakeem-games.novixa.dev/

كل لعبة لها صفحتها وملف الـ APK الخاص بها في مستودعها، وهذه الصفحة تشير إليها مباشرة.
لذلك تحديث أي لعبة في مستودعها يصل إلى هنا تلقائياً، ولا تحتاج هذه الصفحة إلى تعديل
إلا عند تغيير رقم الإصدار أو الحجم المكتوب تحت اللعبة.

## إضافة لعبة جديدة

1. ضع أيقونتها (256×256 بصيغة webp) في `icons/`.
2. في `index.html` انسخ أحد عناصر `<article class="game ...">` وعدّل النص والروابط.
3. أضف لوناً للبطاقة بجانب `.sea` و`.domino` في الـ CSS (`--a` اللون الأساسي، `--b` لون العناوين الصغيرة، `--c` خلفية البطاقة).
4. حدّث العدد في شارة «4 ألعاب».
5. `git commit -am "إضافة لعبة ..." && git push` ثم انشر (انظر بالأسفل).

## النشر

الموقع على سيرفر Novixa، خلف nginx الخاص بـ mailcow و Cloudflare:

```bash
./deploy/deploy.sh
```

- الملفات على السيرفر: `/opt/mailcow-dockerized/data/conf/nginx/hakim-games/` (`releases/` + الرابط `current`).
- إعدادات nginx: [`deploy/hakim-games.conf`](deploy/hakim-games.conf) — عدّلها هنا وليس على السيرفر.
- السكربت يختبر nginx قبل إعادة التحميل ويُرجع الإعدادات السابقة عند الفشل، فلا يتأثر البريد أو المواقع الأخرى.
- الرجوع لإصدار سابق: `ln -sfn releases/<إصدار> current` داخل مجلد الموقع على السيرفر.
